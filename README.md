# МЁРТВЫЙ КВАРТАЛ

Кооперативная настольная игра про зомби: **уровень 1 «Окраина»**. Цифровой прототип (играется в браузере) + полный **Print & Play** для картонной версии.

* 1–4 героя, соло или вдвоём за одним экраном (hot-seat)
* процедурное поле из 9 тайлов (6 в партии, случайные повороты), 4 задания, 7 условий, 3 уровня сложности
* боевая карточная система: масти и **Связки**, карты в руке = **защита**, Раны засоряют колоду, добыча улучшает колоду
* **Тревога → Волна**, смена суток, «Голод» в Глухую ночь, крупные цели, баррикады, ловушки, приманки
* 5 героев с разными ролями и ветками талантов

## Запуск
Откройте `index.html` в браузере (сборка не нужна). Или: `npx http-server -c-1 .`

* `rules.html` — книга правил (таблицы строятся из игровых данных)
* `print.html` — листы для печати: карты 63×88 мм, тайлы 15×15 см, жетоны, планшеты

## Разработка
```
node tools/test.js                         # дымовые тесты движка
node tools/sim.js --all-pairs --games 40   # симуляция баланса ИИ
node tools/trace.js <seed> boris,lisa fuel # журнал одной партии
NODE_PATH=$(npm root -g) node tools/print_check.js out.pdf  # проверка печати (PDF, переполнение текста)
```
Как добавлять героев, карты, врагов, локации и механики — `docs/EXTENDING.md`.
Вся графика нарисована кодом в `src/render/art.js` и заменяется спрайтами одной строкой: `ZG.Art.useImage('ключ', 'путь.png')`.
