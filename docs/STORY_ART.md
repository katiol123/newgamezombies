# Campaign story scene illustrations

Right now every scene is drawn in code — a stylized animated scene (`src/render/storyscenes.js`, one scene per id). All scenes can be viewed from the main menu → “Gallery”. The image below is optional: if you put a file at `art/story/<id>.jpg`, it is shown on top of the animated scene.

The file goes to `art/story/<id>.jpg`. Format **16:9** (e.g. 1920×1080; in the game it is shown at roughly 640×360, at the top of the scene window). Until the file exists, the game shows the animated scene.

Common style (prepend to every prompt, as with the hero portraits):
`graphic novel illustration, bold ink outlines, flat muted colors with rust red and sickly green accents, post-Soviet suburb, cinematic wide shot, horror atmosphere, no text, 16:9`
